Online Learning Engagement and Student Performance Analysis

This project is a data analytics and business intelligence project designed to analyze online learning engagement and student academic performance. The main objective is to transform raw student data into meaningful insights that can help understand learning patterns, engagement levels, and factors associated with student performance.

The project starts with collecting and organizing the dataset, followed by data cleaning and data quality validation to ensure that the data is accurate, consistent, and suitable for analysis. The cleaned data is stored and managed using MySQL, where SQL queries are used to retrieve, filter, aggregate, and analyze the data.

The analyzed data is then connected to Microsoft Power BI to create an interactive dashboard. The dashboard presents important KPIs, charts, graphs, and visualizations that make it easier to understand student engagement and performance patterns.

Key Areas of Analysis
Student information and academic details
Online learning engagement
Student participation and activity
Academic performance
Comparison of engagement and performance
Identification of patterns and trends
Summary of important analytical findings
Project Workflow

Data Collection → Data Cleaning → Data Quality Check → Database Creation → SQL Analysis → Power BI Dashboard → Insights & Interpretation

Tools & Technologies
MySQL – Database creation, data management, and SQL analysis
SQL – Data querying, filtering, aggregation, and analysis
Power BI – Interactive dashboards and data visualization
Excel/CSV – Dataset/source data
GitHub – Project documentation and version control
Project Outcome

The final outcome is an interactive Power BI dashboard supported by SQL analysis, providing a clear view of online learning engagement and student performance. The project demonstrates practical knowledge of database management, SQL, data cleaning, exploratory analysis, visualization, and business intelligence, while converting raw data into understandable and actionable insights.
